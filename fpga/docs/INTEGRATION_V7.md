# OfflineV7 Integration — 功能移植版

基于 KeyboardPercussion_OfflineV6_RouteOpt1，合并用户提供的 StateLightV5_ramfix 功能。此包不包含第二包的 HPG3 扩展。

## 增加及修复

- 六个主视图：频谱、波形、李萨如、HALLPAD、音频时间、鼓棒。
- 李萨如图由 FFT 两个主要局部峰重建，128×128 橙色图，不是两路独立模拟输入的实测 XY。
- 音频时间：实体键已识别的事件至该版本音源非零采样标记的内部计时，随后按 68 个音频边界估算输出流水线。不是从手指接触到喇叭出声的实测延迟；68 常数没有硬件验证。
- 左右棒独立工作和校准：只接一根也可完成上电校准；另一根拔出/离线/校准不再禁止本侧触发。短暂通讯中断保留校准，重新建立采样时间基准。
- 手动校准不复位 MPU6050。鼓棒菜单分为校准、左右状态、左右音色。
- 方向协议统一为 0 侧击、1 下击、2 上击。旧手机若沿用另一种编号，需要按此适配；线协议字段大小不变。
- 灯光亮度乘法/除法分拍，历史 RAM 专用读阶段，协议版本判断简化；保留 RouteOpt1 每键提交分布寄存器和灯帧缓存单写口。

## 保留

HPG1/HPG2、35 实体键完整映射和结束恢复、自然完成评分、原音色、原约束/引脚和严格 5ms 鼓棒时隙均保留。原有中文 22×22 字模逐行和逐像素比对不变，增加新页面的 22×22 字符。未加入 AudioKitV4 的其他声音库。

## 使用

打开本目录 KeyboardPercussion.gprj，顶层 keyboard_top。推荐使用新解压目录重新综合和布局布线，不复用旧网表。工具 midi_to_hpg.py 仍输出 HPG2。SD 要求 FAT32，根目录大写 8.3 .HPG，最多32首。

本包只有源工程，没有新生成的 .fs。Verilator 静态检查与仿真见 verification/V7_RESULTS.md；未执行 Gowin 综合、布局布线、STA 和实机测试，因此不能保证布线成功或50MHz时序达标。
