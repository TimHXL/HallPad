# 0 dB模拟音量版

基于KeyboardPercussion_DrumVolume，仅修改src/tlv320dac3100_init.v。

FPGA单音源模拟衰减-6dB改为0dB；外部输入单音源100%时-6dB改为0dB；双音源100%时-12dB改为-6dB，保留6dB混音余量。初始化0x268C同步改为0x2680。外部输入音量衰减表、FPGA主音量和数字限幅保持不变。

保留新线序、鼓棒参数更新、TimingOpt2、36声部和8次谐波。此前说明中音量数值以本说明为准。

0dB表示此级不衰减，不保证实际输出功率。比上版增加6dB，首次测试请从低主音量逐步提高，检查是否破音。数字限幅不能阻止后级功放及模拟混音削顶。

已核对初始化及运行时常量；未进行RTL仿真、Gowin综合、布局布线和实板验证。打开KeyboardPercussion.gprj重新完整编译。
