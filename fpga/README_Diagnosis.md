# Drum80_Diag：摇杆左右互换与鼓棒通信诊断

完整工程基于Drum80。优先阅读本文，其余功能及SD卡操作继续按README_Drum80/README_OfflineGuide执行。

## 本次修改

摇杆水平调制深度交换：低ADC侧全行程由32改为127，高ADC侧由127改为32；上下弯音正负、中心、端点、灵敏度和手机控制均保留。实际RTL测试覆盖水平两端及上下弯音两端。

鼓棒页区分PLG与MPU通信：PLG未插入显示UNPLUG；已插入但通信离线显示OFFLINE；通信在线但未校准显示UNCAL，真正校准中才显示CAL。底部摘要在线未校准由原CAL改为UNC。

增加最近一次MPU通信错误的锁存，正常采样不会抹掉；手动/自动校准开始时清零。逻辑左棒放低字节、右棒放高字节，遵守现有DRUM1为物理左的交换规则。最近错误不为0且尚未就绪时，选中对应棒的头部显示“OFF   xx”或“UNCAL xx”，xx为两位十六进制错误。最近错误只是历史诊断，不代表当前这一次事务仍失败。

## 为什么OFFLINE和UNCAL跳动

界面直接采用MPU驱动online，完全不是PLG引脚反相。有效采样成功置online=1；连续3次采样事务失败清零并重新探测/配置，故反复成功与失败会出现OFFLINE/UNCAL交替。上电未进入鼓棒页时不校准，稳定在线后的UNCAL本身正常。

这能确定在线信号在变化，不能仅凭屏幕判断是线缆/上拉/供电/干扰还是FPGA时序违例。先前布线报告未满足50MHz，新版尚未重新布局布线。此次不通过屏蔽离线、放宽错误门槛或增加自动校准掩盖故障，也未随意改变I2C速率。
