# Offline V9：手机下载与本地曲谱

基于 KeyboardPercussion_OfflineV8_UIFix，配套 Android_OfflineV9_Patch。
打开 `KeyboardPercussion.gprj` 重新综合、布局布线并生成烧录文件。此包没有经过 Gowin 布局布线验证，也不含声称可用的新 .fs 文件。

## 本版功能

- 手机“下载到SD”：原始 MIDI 全部非空旋律音轨，另加 ALL 合并音轨；在设备中仍可选独立音轨练习或自动播放。
- 手机和电脑用相同 22×22 字模、整数计时、分配算法生成 HPG3 v4；默认转换的文件内容逐字节相同。输入 MIDI、标题、移调等选项必须相同；手机当前使用原始文件、移调0、默认自动键位和最大10音和弦，不使用手机当前键位/AB选段覆盖文件。
- 保留 HPG1、HPG2、旧 HPG3 v3 读取。新 HPG3 v4 必须配本版 FPGA，扩充至32字标题、最多256原始音轨+ALL。仅打击乐通道10和纯元数据轨不成为旋律选择项。
- SD 根目录最多256首 .HPG，支持普通 FAT32 空卡建文件、碎片文件、双FAT、扩展根目录；不是要求预放占位文件。
- 手机可刷新、删除、改文件名、同名覆盖、取消。同名 .TMP 会比较已写扇区后继续；整文件读回 CRC32 成功后才发布 .HPG。卡内成功保存后断电仍在。
- 超过35种映射音高/单次10音和弦的音符按既有规则选择，并报告跳过数量。每个练习/播放对象仍最多4096条事件，不是无限长度。MIDI格式0/1、PPQ，最多8MiB；HPG最多64MiB。
- 中英混合曲名连续移动，50MHz下精确平均33像素/秒（1.5个22像素字宽），不足8字不滚动；没有逐字跳动。
- 本地曲谱菜单使用“本地曲谱 / 进入”；只新增“本、地”22×22字模，原始字模逐像素保留。
- 自动播放期间 BLE HELLO、心跳、状态、参数读写不等待播放器的音符输入口；蓝牙重连/失联清理不再清掉本地播放音符。
- 浏览本地菜单允许键位设置；曲目加载/临时键位有效时保护这些键位，其他全局设置不一概拒绝。练习上传与本地播放仍共用一份RAM，因此不能同时装入两份曲谱。
- GET_KEYS读回当前生效的完整临时键位；应用/恢复触发revision变化，安卓自动刷新，显示临时键位提示。
- 自动播放LED显示当前真正保持的音符，跟随练习保留目标与黄/绿/红判定指引；暂停/释放同步处理。
- 不接卡也可上电，稍后插卡自动初始化；无卡检测引脚，空闲时约每1秒探测一次。拔卡识别后清除目录和标题，插回自动重新挂载，不必复位整机。一次SD底层超时和重新初始化还会增加检测等待时间。

## 使用

1. 更新FPGA及安卓源码补丁，两端必须配套；安卓包是源码补丁，不是APK。
2. SD卡用512字节逻辑扇区的FAT32（超级软盘或第一MBR FAT32主分区），不支持exFAT/FAT16。
3. 手机打开曲谱，点“下载到SD”，全部音轨转换并写入；播放期间先停止。浏览“本地曲谱”目录时也可下载。
4. 文件名使用大写8.3，例如 S1234567.HPG；真正曲名在HPG内，FPGA显示曲名而非该短文件名。
5. 电脑批量工具：进入 `tools` 目录后执行 `powershell -ExecutionPolicy Bypass -File .\Convert-All.ps1 -InputFolder ".\MIDI_INPUT" -OutputFolder ".\HPG_OUT"`。每BANK最多256首，复制一个BANK中的 .HPG 到SD根目录；json/csv为电脑报告，不必复制。电脑导入和手机导入都必须保证根目录总数不超过256。
6. 同名未完成下载可重试继续；放弃后可用电脑删除 .TMP。正常取消保留TMP用于续传。
