# 单双音源均无额外模拟衰减

基于KeyboardPercussion_Volume0dB，仅修改src/tlv320dac3100_init.v：移除双音源额外6dB混音衰减。

100%主音量时，FPGA单音源、外部输入单音源、双音源均为0dB模拟衰减。低音量时保留原主音量控制：有外部输入时使用模拟衰减表，纯FPGA由数字主音量调节。初始化保持0x2680。

其他鼓棒参数、引脚、音频合成及TimingOpt2不变。此前说明中的双音源-6/-12dB余量均以本说明为准。

两路同时大幅度输入可能导致模拟混音或功放削顶，数字限幅无法保护模拟外部输入。已核对运行时常量及与基线差异；未进行Gowin编译、RTL仿真、最终时序及实板验证。
